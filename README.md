# KALU v1

نسخه اول رابط کاربری سیستم مدیریت مدل‌های کفش.

## اجرا
پیش‌نیاز: Node.js LTS

```bash
npm install
npm run dev
```

سپس http://localhost:3000 را باز کنید.

رمز آزمایشی: `1234`

## وضعیت
این نسخه رابط کاربری و جریان کاری اولیه را آماده کرده و فعلاً برای تست سریع داده‌ها را در localStorage ذخیره می‌کند.
اتصال واقعی Supabase، احراز هویت امن، Storage تصاویر، RLS و سطح دسترسی کاربران در مرحله بعد انجام می‌شود.

فایل `supabase/schema.sql` ساختار اولیه دیتابیس را دارد.
